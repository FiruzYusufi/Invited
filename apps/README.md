# Invited Project - Приложения

Этот файл содержит инструкции по запуску приложений и данные для входа.

## Доступные приложения

1.  **Client** (`apps/client`): Интерфейс для гостей и личный кабинет клиента.
    - Порт: 3000
    - Запуск: `pnpm run dev --port 3000`

2.  **Manager** (`apps/manager`): Панель управления для организаторов.
    - Порт: 3001
    - Запуск: `pnpm run dev --port 3001`

3.  **Admin** (`apps/admin`): Глобальная панель администратора.
    - Порт: 3002
    - Запуск: `pnpm run dev --port 3002`

## Требуемые зависимости и системные компоненты

Для работы проекта необходимо установить:

1.  **Node.js** (v18.0.0 или выше)
2.  **PNPM** (Глобально): `npm install -g pnpm`
3.  **Prisma CLI** (Обычно идет в составе dev-зависимостей, но можно установить глобально): `npm install -g prisma`

## Порядок запуска (Первый раз)

1.  Установить все зависимости монорепозитория:
    ```bash
    pnpm install
    ```
2.  Сгенерировать клиент Prisma для работы с базой данных:
    ```bash
    pnpm db:generate
    ```
3.  Применить миграции к базе данных (создать таблицы):
    ```bash
    pnpm db:migrate
    ```
4.  Заполнить базу тестовыми данными (логины выше):
    ```bash
    pnpm db:seed
    ```
5.  Запустить все приложения:
    ```bash
    pnpm dev
    ```

## Переменные окружения (.env)

Убедитесь, что в корне проекта или в папках приложений созданы файлы `.env` с параметром:
- `DATABASE_URL`: Путь к вашей базе данных SQLite/PostgreSQL.
- `JWT_SECRET`: Секретный ключ для авторизации.
